# Book Alchemy

A small digital library built with Flask and Flask-SQLAlchemy (Masterschool Codio project).

## Features

- Add authors and books (the book form has an author dropdown)
- Home page with book covers (Open Library, via ISBN) and sorting by title or author
- Keyword search over book titles and author names
- Delete a book; an author without other books is removed too

## Run it

    pip install -r requirements.txt
    python3 app.py

The app runs on port 5002.
